# Project-Local Sounds

The Copilot core distribution does not include PPT Master's bundled WAV sound
library.

Use only user-supplied audio that already exists in the project and satisfies
the format required by the selected animation, transition, narration, or video
workflow. Reference it by a validated project-relative path.

Do not run `sound_sync.py`, select bundled sound IDs, or download a sound
library automatically. Silence is the default.
